# Flores de Primavera 🌻

Página interactiva gratuita para compartir.

## Publicar en GitHub Pages
1. Crea una cuenta en GitHub.
2. Crea un repositorio público, por ejemplo: `flores-primavera`.
3. Sube `index.html`, `style.css` y `script.js`.
4. En el repositorio entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona `main` y la carpeta `/ (root)`.
7. Guarda y espera a que GitHub genere tu enlace.
